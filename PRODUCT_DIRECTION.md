# Spartan X Product Direction

## Core Position

Spartan X is a stoic proof system for self-command.

It is not a military app, sci-fi interface, fantasy selection program, or tactical roleplay product. The hard edge comes from standards, evidence, restraint, and honest reflection.

## Core Loop

Use this loop as the product spine:

`Claim -> Practice -> Friction -> Reflection -> Proof -> Standard`

The user makes or selects a claim. The system assigns a practice. Friction appears. The user reflects. Proof is logged. The standard only moves when evidence supports it.

## Naming Rules

Keep the mechanics from the PRD. Adjust names that sound military, sci-fi, theatrical, or roleplay-heavy.

Legacy PRD names can appear in internal mapping notes only. They must not appear as user-facing navigation labels, module subtitles, onboarding copy, or status language.

| Avoid as primary UI language | Use instead |
| --- | --- |
| Command Deck | Today |
| Mission | Practice |
| First Order | First Practice |
| AAR | Reflection |
| Debrief | Reflection |
| Hold the Line | Pause / Recenter |
| Selection | Assessment |
| Induction | Foundation |
| Recruit Qualified | Foundation Confirmed |
| AI Command Officer | Guide / Standard Guide |
| War College | Principles / Practice Library |
| Squad Room | Circle / Accountability |
| Integrated Pressure Trial | Pressure Practice |
| Operator | Execution |

## Product Feeling

The app should feel like a private, premium standard system:

- calm
- exact
- restrained
- serious
- evidence-led
- stoic

It should not feel like:

- military cosplay
- a game
- a punishment system
- motivational hype
- gym-bro tracking
- sci-fi command software

## Safety Rule

Spartan X must never reward recklessness, pain worship, self-punishment, or unsafe escalation. Recovery, scaling, and honest reporting are part of the standard.
